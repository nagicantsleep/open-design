### 🌟 Codename: *更稳的底座*

🧭 **`53 个 PR` · `16 位贡献者` · `21 天`** — **减少打断，让创作继续。** 相比 0.24.1，本次新增独立的动效设计流程，也修复了日常创作中的多处中断：发送受阻时保留草稿，重新打开项目后保留预览选择，云端更新经过你的确认才会替换本地文件。

## 🔥 亮点

- 🎞️ **动效设计有了专门的入口。** 在首页或社区选择「动效设计」，从 5 个内置示例开始，也可以在 `@` 列表中选用动效技能。明确要求视频时，可获得可编辑源文件和 MP4；交互动画保留可运行的 HTML。离开当前预览后，声音会停止。 (#8619)
- 🧭 **从设计方案顺畅进入制作。** 设计任务可以根据普通文字方案继续制作，不再因回复缺少内部标记而失败。只要方案的请求会停在方案阶段；制作完成后，模型提供的后续建议也能重新显示。 (#8356, #8770) 感谢 @itscheems。
- 🔄 **其他设备的修改，由你决定何时同步。** 应用云端更新前，可以先确认。勾选 24 小时内不再提醒并选择「暂不同步」，只会关闭这台设备上该项目的提醒；需要时仍可主动打开更新并确认同步。 (#8683) 感谢 @PerishCode。
- 🖼️ **新产物及时出现，预览保留你的选择。** 任务完成后会刷新文件列表，识别刚生成的图片等文件。你手动选择的预览不会被抢走；重新打开项目时，也会保留之前选中的「设计文件」视图。 (#8744, #8745)
- 💳 **额度不足时，草稿留在首页。** 如果首页已因额度不足拦住发送，只有确认余额或套餐额度可用后才会继续。检查失败会保留弹窗，关闭弹窗会保留草稿。钱包余额为零但 Coding Plan 仍有可用额度时，仍可正常使用。 (#8688, #8775)
- 🤖 **模型下架或历史附件变多时，更容易继续创作。** AMR 中选中的模型下架后，可改用目录中的默认模型，并明确提示替换结果。长对话会限制重复发送的图片和 PDF 总大小，减少请求过大导致的失败；需要旧附件时，模型仍可重新读取。 (#8602, #8767) 感谢 @Siri-Ray。
- 🔑 **登录后即可使用 OpenDesign Hosted。** 欢迎页登录完成后直接进入 Hosted，本地 AI 和 API Key 入口仍然可用。登录过程中会显示进度、取消操作，以及重新打开浏览器登录页的入口。 (#8567)
- 🔎 **诊断保留有用线索，减少重复上传。** 同一种接口故障会合并处理，AMR 失败时可以收集该次任务的相关记录。Windows 日志文件更替后，也会继续遵守用户同意的采集范围。 (#8461, #8488, #8487) 感谢 @Siri-Ray。

> 📥 **下载：** [Open Design 0.25.0](https://github.com/nexu-io/open-design/releases/tag/open-design-v0.25.0)。

## ✨ 新增

### 🎨 动效与模板

- **5 个可直接使用的动效示例：** Motion Future、Product Promo、Showreel、UI Morph 和 Visual Lesson。示例附带脚本、字体、音轨和预览，便于继续编辑。视频导出会检查 MP4 是否可播放；导出失败时保留可编辑源文件。 (#8619)
- **Aster Atelier 建筑工作室网站模板。** 从可编辑的本地示例开始制作网站，包含章节导航、服务介绍、常见问题和联系表单演示，并提供中英文示例提示词；演示表单不会发送真实联系请求。 (#8314)

## 🔁 改进

### 💬 日常操作

- 点击发送后立即清空输入框。发送未能继续时，会恢复文字、附件、上下文和引用；如果你已开始写下一条消息，则不会覆盖新草稿。 (#8380) 感谢 @Siri-Ray。
- 导出、登录、更新、存储、额度和停止任务的提示，在全部 19 种支持的语言中改为更清楚的说明。导出失败时不再直接展示底层技术错误。 (#8620) 感谢 @lefarcen。
- 设置页和输入框的模型选择列表中，鼠标悬停可查看被截断的完整模型名称。受套餐限制的模型仍优先显示升级原因。 (#8409) 感谢 @PratikRai0101。

## 🐛 修复

### 💬 对话与设计任务

- 较早的对话记录加载完成时，不再覆盖当前已经显示的思考内容。 (#8167)
- 稍后才生成的记忆卡片会留在原来的对话中，切换对话或刷新后也不会串到其他对话。 (#8065)
- 回答澄清问题后，上一项已完成任务的状态、耗时和折叠步骤会保留，同时单独展示正在启动的后续任务。 (#8401) 感谢 @Siri-Ray。
- 继续旧设计对话时，会保留原始请求、附件和相关历史。纯文字回复可以正常结束，尚未完成的任务仍可继续处理。 (#8356)
- 自动制作完成后，可以再次显示模型给出的后续建议。点击建议会填入输入框，由你决定是否发送。 (#8770) 感谢 @itscheems。

### 🗂️ 项目、文件与预览

- 空项目列表可以正常结束加载；读取失败时显示错误和重试入口，不再一直转圈或误报没有项目。切换工作区后，会停止查询上一份项目列表的状态。 (#8443, #8442) 感谢 @Siri-Ray。
- 同一批上传的同名文件，按提交顺序添加文件名后缀，确保返回的名称与文件内容对应，并保留已有文件。 (#8742)
- 任务完成后能识别新生成的文件；服务器尚未保存最新标签选择时，可在恢复项目时使用较新的本地选择。 (#8744, #8745)
- 窗口高度较小时，可以滚动查看首页标题和完整输入框。 (#8649) 感谢 @itscheems。
- 切换到从右向左书写的语言后，悬停被截断的工作区名称，仍能正确展示隐藏部分。 (#8692) 感谢 @Siri-Ray。
- 已缓存的应用内活动，在授权仍有效时可以应对短暂断网和重启；已撤回或过期的活动不会因旧缓存再次出现。 (#8676)

### 🧠 模型与本地智能体

- 多个进程同时刷新登录凭据时，可以通过已有的安全重试流程恢复，减少任务直接失败的情况。 (#8160) 感谢 @Marinski。
- Antigravity 在 Windows 上可以启动包含较长提示词的任务，并在聊天中逐步显示回复和工具操作。 (#8594) 感谢 @lefarcen。
- Windows 上 AMR 已完成的回答，不再仅因应用关闭了已结束的智能体进程而被标记为失败。 (#8514) 感谢 @Siri-Ray。
- 低于 Windows 10 1809 的系统导致 AMR 无法运行时，会提示更新 Windows，不再提供无法解决问题的重试操作。 (#8629) 感谢 @Siri-Ray。
- OpenCode 使用技能时，可以读取技能自身附带的资源文件，减少不必要的权限提示。 (#8178) 感谢 @aron-intframe。
- 保存应用设置后，Pi 仍会使用已指定的其他配置目录。 (#8119) 感谢 @L4XB。
- 内置 Vela CLI 更新至 0.1.6，为包含大量图片或 PDF 的对话启用历史附件大小限制。 (#8767) 感谢 @Siri-Ray。

### 🖥️ 桌面稳定性

- macOS 临时目录路径过长时，不再导致应用所需的本地服务无法启动。 (#8002) 感谢 @abhi-zit77。
- 操作系统网络缓冲区耗尽时，桌面应用会停止反复重试内部请求，减少卡住的时间。 (#8283) 感谢 @chenlei-github。
